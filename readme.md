# Relay

Relay is a minamalistic chatting site built specifically for school clubs.

## Features

Subspaces to organize clubs.

## Prerequisites

- Rust
- Cargo

## Running

```bash
cargo run --bin make_db
cargo run --bin main
```

Then open http://localhost:3000 in your browser.
